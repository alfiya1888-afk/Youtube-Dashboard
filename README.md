# 📊 YouTube Growth & Engagement Intelligence Dashboard

## 📌 Project Overview
The YouTube Growth & Engagement Intelligence Dashboard is an interactive Excel-based analytics project designed to monitor and analyze YouTube channel performance.
This dashboard provides insights into video engagement, audience interaction, upload trends, and subscription growth using visually appealing charts and KPI cards.

The project helps content creators, analysts, and marketers understand:

Which content performs best
Audience engagement patterns
Growth trends over time
Optimal upload timing and video duration

## 🎯 Objectives

* Analyze YouTube video performance data
* Track engagement metrics such as views, likes, and comments
* Monitor subscriber growth trends over time
* Identify high-performing video categories
* Compare video duration with average views
* Visualize monthly and weekly upload performance trends

## 🛠️ Tools & Technologies Used

* **Microsoft Excel** – Primary platform for data analysis and dashboard creation
* **Pivot Tables & Pivot Charts** – Used for dynamic data summarization and visualization
* **Slicers & Filters** – Enabled interactive data exploration
* **KPI Cards** – Displayed key performance metrics clearly
* **Conditional Formatting** – Enhanced data readability and insights
* **Data Cleaning & Formatting** – Ensured data accuracy and consistency

## 📈 KPI Metrics

* **Total Likes**: 20,997,027
* **Total Comments**: 6,871,920
* **Total Subscribers Gained**: 2,554,537

These metrics provide insights into overall audience engagement and channel growth performance.

## 🔍 Insights Derived
* Music videos generate the highest engagement.
* Upload timing impacts performance significantly.
* Long-form and short-form content outperform medium-length videos.
* Subscriber growth correlates strongly with engagement spikes.
* Weekend uploads tend to attract better interaction.
